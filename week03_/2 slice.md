Слайс - главная структура данных Go

Слайс - структура поверх массива:
- len - длина видимой части
- cap - ёмкость, сколько элементов можно добавить (длина базового массива)
- реальный массив скрыт внутри

```go
s := []int{1, 2, 3}
s = append(s, 4)
```

Slice (= Срез) - тип данных, последовательность динамической длины. Аналоги из других ЯП: динамический массив (при создании не указывается количество элементов); список.

Удобны, расширяемы, не обязательно знать зарание кол-во элементов.


---

### make, append, copy

make - лучший вариант для предвыделения памяти.
append может пересоздать внутренний массив -> старый ссылки станут неактуальны.

```go
s := make([]int, 0, 5)
s = append(s, 10)

s[100] = 11 // panic. Не можем обратится к элементу которого нет в срезе.
```

---

### Срезы слайсов (a[start:end])

Срез - слайс внутри другого слайса.
Оба используют один и тоже underlying array.

```go
a := []int{1,2,3,4}
b = a[1:3] // 2,3
```
