# Горячие клавиши VS Code и разработка на Go

ПКМ в редакторе: Список команд.

## 1. Навигация по коду
* **Ctrl + P** (Быстрое открытие): Просто введите первые буквы имени файла. Профи не кликают по папкам, они находят файлы мгновенно.
* **Ctrl + G** (Переход к строке): Когда линтер или тесты выдают ошибку на строке 142, они нажимают `Ctrl + G`, вводят `142` и сразу оказываются там.
* **Ctrl + Shift + O** (Навигация по символам): Позволяет мгновенно прыгнуть к конкретной функции, методу или переменной внутри открытого файла. Если ввести `:` после вызова, VS Code сгруппирует их по категориям.
* **F12** и **Alt + F12**: `F12` мгновенно переносит к месту, где была объявлена функция или переменная. `Alt + F12` (Peek Definition) показывает это объявление в маленьком всплывающем окошке, не уводя из текущего файла.

## 2. Мультикурсоры и «умное» выделение
* **Ctrl + D** (Множественный выбор): Выделите слово и нажимайте `Ctrl + D`. VS Code найдет следующие такие же слова в файле и создаст там курсоры. Вы можете переименовать переменную или изменить теги во многих местах одновременно.
* **Alt + Клик мыши**: Ставит курсоры в любые произвольные места на экране.
* **Shift + Alt + Стрелки (вверх/вниз)**: Мгновенно дублирует текущую строку кода. Больше никакого `Ctrl + C` -> `Enter` -> `Ctrl + V`.
* **Alt + Стрелки (вверх/вниз)**: Перемещает всю строку (или выделенный блок) выше или ниже по коду.

## 3. Интегрированный терминал и Git
* **Ctrl + \`** (обратный апостроф): Открывает и скрывает встроенный терминал. Все команды, тесты и сборщики запускаются прямо внутри редактора.
* **Встроенный Git**: Вместо консольного `git status` они используют вкладку *Source Control* (**Ctrl + Shift + G**), где визуально проверяют изменения (диффы), пишут коммиты и пушат код одной комбинацией клавиш.

## 4. Сниппеты и AI-ассистенты
* **Emmet** (для веб-разработчиков): Профи не пишут `<div><p class="text"></p></div>`. Они пишут `div>p.text` и нажимают `Tab`. VS Code сам разворачивает это в готовую HTML-структуру.
* **Пользовательские сниппеты** (Snippets): Они создают свои шаблоны. Например, введя `rfce` + `Tab`, получают готовый каркас React-компонента.
* **AI** (GitHub Copilot / Cursor): Современный стандарт — использование нейросетей для генерации шаблонного кода, написания тестов и быстрого поиска багов прямо в редакторе.

## 5. Zen Mode
* Нажатием **Ctrl + K**, затем **Z** они включают *Zen Mode*. Исчезают все боковые панели, вкладки, статус-бары. Остается только чистый код по центру экрана.
* Режим одного активного окна, где нет вкладок (ведь любой файл открывается за секунду через `Ctrl + P`, а переключаться между последними открытыми файлами можно через `Ctrl + Tab`).	

## 6. Независимость от мыши
* **Ctrl + \\** (Разделение редактора): Мгновенно дублирует вкладку и делит экран пополам (split screen). Профи всегда держат перед глазами файл с кодом слева и файл с тестами (`_test.go`) справа.
* **Ctrl + 1, Ctrl + 2, Ctrl + 3**: Переключение между разделенными окнами кода без использования мыши.
* **Ctrl + B** (Скрыть/показать боковую панель): Нажатием `Ctrl + B` вы убираете дерево папок слева, отдавая 100% экрана под код. В сочетании с быстрых поиском файлов через `Ctrl + P` боковая панель вообще становится не нужна.
* **Shift + Alt + F** (Принудительный формат): Хотя у вас стоит автоформат, иногда нужно выровнять код «здесь и сейчас», не дожидаясь сохранения или смены фокуса.

## 7. Golang
Официальный плагин Go от Google дает глубокую интеграцию, и вот как профи выжимают из нее максимум:

### 7.1. Генерация шаблонного кода (Бойлерплейта)
* **Ctrl + Shift + P** -> `Go: Add Tags to Struct Fields`: Профи не пишут `json:"id"` вручную для каждого поля структуры. Выделяете структуру, вызываете эту команду, и VS Code сам генерирует теги (по умолчанию snake_case).
* Просто напишите букву(ы).

### 7.2. Тесты
* **Ctrl + Shift + P** -> `Go: Toggle Test File`: Мгновенное переключение между файлом кода (например, `main.go`) и файлом его тестов (`main_test.go`). Не нужно искать его в дереве файлов.
* **Интерактивные кнопки над функциями**: Обратите внимание на мелкий блеклый текст `run test | debug test` прямо над вашими тестовыми функциями `func Test...`. Клик по ним запускает изолированный тест прямо в консоли VS Code, избавляя от необходимости писать громоздкие команды `go test -v -run ...` в терминале.
* **Ctrl + Shift + P** -> `Go: Generate Unit Tests for Function`: Поставьте курсор на сигнатуру сложной функции, вызовите эту команду, и VS Code сам сгенерирует для нее табличный тест (Table-driven test) со всеми заготовками под входные и выходные данные.

### 7.3. Быстрая диагностика и интерфейсы
* **Shift + F12** (Найти все ссылки): Показывает лаконичный список всех мест во всем проекте, где вызывается эта функция или используется эта структура.
* **Ctrl + Shift + P** -> `Go: Implement Methods`: Если вам нужно, чтобы структура реализовала определенный интерфейс, эта команда сгенерирует заглушки для всех необходимых методов интерфейса автоматически.
