### JOIN

JOIN - способ объеденить данные из двух таблиц по связующему полю.

1. База берёт строки из таблицы А
2. Находит подходящие строки в таблице В
3. Собирает результат в одну выборку

```sql
{ USERS }
id  name
1   Ivan
2   Anna
3   Dima <- без заказов
4   Oleg <- без заказов

{ ORDERS }
id  user_id    amount
1   1          500
2   1          300
3   2          900
4   2          150 <- заказов нет в users
```

JOIN связывает данные по ключу.

Это основа реляционных БД: без JOIN запросы превращаются в хаос.

#### INNER JOIN

Только пересечение.
Возвращает только те строки, у которых есть совпадение в обеих таблицах.
Если связи нет - строка не попадёт в результат.

```sql
{ ORDERS }
amount  name
500     Ivan
300     Anna
150     Dima
800     Oleg
```

#### LEFT & RIGHT JOIN

LEFT JOIN - берём все строки из левой таблицы и только совпавшие из правой.
Если совпадения нет - справа NULL.
Все из левой + совпавшие справа.

```sql
name    amount
Ivan    500
Anna    300
Dima    150
Oleg    800
```

RIGHT JOIN - наооборот: все строки из правой таблицы и совпавшие из левой.
Все из правой + совпавшие слева.

```sql
amount   name
500      Ivan
300      Anna
150      Dima
800      Oleg
```

#### FULL OUTER JOIN

Всё из обеих таблиц.
Возвращает всё:
1. Совпавшие строки
2. Строки только из левой таблицы
3. Строки только из правой таблицы

Если совпадения нет - NULL в недостающих колонках

```sql
name    amount
Ivan    500
Anna    300
Dima    150
NULL    999 <- заказ без пользователя
```

#### Когда какой JOIN использовать

- INNER JOIN: нужны только связанные данные
- LEFT JOIN: важны все строки из левой таблицы
- RIGHT JOIN: важны все строки из правой таблицы
- FULL JOIN: нужны все данные со всех сторон

JOINы - про контроль: сам выбираешь, что включать в результат.

---

Какой JOIN вернет все строки из обеих таблиц, даже если нет совпадений, заполняя отсутствующие значения NULL?


FULL JOIN.
В SQL существует несколько видов JOIN, каждый из которых решает свои задачи:

Во-первых, INNER JOIN: Возвращает только совпадающие строки из обеих таблиц.
Во-вторых, LEFT JOIN: Возвращает все строки из левой таблицы и совпадающие строки из правой. Если совпадений нет, справа будут NULL.
В-третьих, RIGHT JOIN: Возвращает все строки из правой таблицы и совпадающие строки из левой. Если совпадений нет, слева будут NULL.
В-четвертых, FULL JOIN: Возвращает все строки из обеих таблиц. Если совпадений нет, недостающие значения заменяются на NULL.
В-пятых, CROSS JOIN, который в опросе не заявлялся, но его тоже стоит отметить. Возвращает декартово произведение строк. Это означает, что он соединяет каждую строку одной таблицы с каждой строкой другой, в результате чего получается набор всех возможных комбинаций строк из обеих таблиц.

Пример FULL JOIN:
sql
-- FULL JOIN
SELECT users.name, orders.amount
FROM users
FULL JOIN orders ON users.id = orders.user_id;

‼️ Таким образом, FULL JOIN — это единственный тип JOIN, который возвращает все строки из обеих таблиц, даже если нет совпадений.
