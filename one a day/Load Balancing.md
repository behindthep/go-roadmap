Load Balancing - распеределение нагрузки между несколькими серверами.
Если один сервер работает - он легко падает под нагрузкой.
Когда серверов несколько, балансировщик решает, на какой сервер отправить каждого нового пользователя, чтобы работало быстро и стабильно.

1) Распределяет пользователй равномерно
2) Если один сервер падает - отправляет пользоватлей на другие
3) Ускоряет отклик сайта

Без него сервси легко падает под нагрузкой.

Load Balancing - основа нагруженной системы. Нужен везде, где много трафика:
* Интернет магазины
* Банки
* Соцсети
* Игры
* Видеостриминг

С ним сайты работают стабильнее и выдерживают высокие нагрузки.

### Алгоритмы балансировки

1. Round Robin
по очереди: A -> B -> C -> A -> ...
2. Least Connections
На свободный сервер, где меньше активных запросов
3. IP Hash
Один и тот же пользователь всегда попадает на один и тот же сервер.

### Health Checks

Балансировщик регулряно проверяет, живы ли серверы.
Если сервер не отвечает - он исключается из списка.
Пользователи не попадут на сломанный сервер.
