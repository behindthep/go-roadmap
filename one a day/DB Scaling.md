Горизонтальное масштабирование — как растут сервисы

Это рост системы за счёт добалвния новых инстансов сервиса.
Не усиливаем один сервер, а запускаем несколько одинаковых копий и распределяем нагрузку.
              -  Сервис
Пользователь --  Сервис
              -  Сервис

Вертикальное масштабирование - увеличаем ресрусы (CPU, RAM) одного сервера.
Ограничено железом.

Горизонтальное масштабирование - добавляем новые серверы.
Можно добавлять новые узлы. Сервис должен быть без состояния. Данные нельзя хранить в памяти одного инстанса.
Сервис -> 1 БД
Сервис -> 2 Кэш
Сервис -> 3 Сессии
Состояние вынесено наружу.

Балансировщик нагрузки распределяет запросы между инстансами и отправляет трафик только на рабочие сервисы.
                                        X Недоступен
Пользователь -> Балансировщик нагрузки -> Сервис
                                       -> Сервис
Клиент всегда работает с живыми инстансами.
