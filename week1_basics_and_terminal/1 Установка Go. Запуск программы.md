Go - ЯП, разработанный Google в 2009.
Позиционируется как серверный ЯП, благодаря **строгой типизации**.

- **Компилируемый**: Код компилируемого языка выполняется намного быстрее, чем интерпритируемого.
- **Многопоточный**: Go умеет тщательно использовать все ресурсы системы, всех ядер процессора. Python, Java расчитаны на 1 ядро.
Высокая производительность, при низкой нагрузке на систему.
С помощью **goroutine** можем разбивать множество процессов, выполнять их параллельно. Они занимают очень мало места, требуют мало ресурсов системы.

С *https://golang.org/* скачать **Go SDK** (Software Development Kit) — пакет инструментов разработчика.
В него входят:
• Компилятор — превращает код на Go в готовый исполняемый файл (.exe для Windows, бинарник для Linux/macOS).
• Стандартная библиотека — огромный набор встроенных готовых функций для работы со строками, сетью, файлами и веб-серверами.
• Утилита go — инструмент в командной строке (CLI) для запуска, тестирования, форматирования и сборки программ.

```bash
# Проверка установки
go

# Запуск программы: Компиляция во временный исполняемый файл на жестком диске (в папке временных файлов ОС) и его запуск. После завершения работы программы он удаляется.
go run main.go
go run -work main.go # путь к созданной временной папке

# Собирает из файла исполняемый .exe файл (бинарник для Linux/macOS) в текущую папку проекта. 2 MB - мало, Go производительный
go build main.go
```

Расширение Go (от Google) в **VS Code** связывает редактор с инструментами разработки:
1. Языковой сервер gopls — «умные» функции: автодополнение кода (IntelliSense), переход к определениям функций, поиск ошибок на лету и автоформатирование при сохранении.
2. Отладчик dlv (Delve) — добавляет графический дебаг: ставить точки останова (breakpoints) и пошагово проверять значения переменных.
3. Набор линтеров и утилит (загружаются по кнопке Install All) — автоматизируют рутину: генерацию тегов для структур (json:""), заготовки для тестов и глубокий анализ кода на скрытые баги (staticcheck).

### Сферы применения языка Go

- Web: Построение web-сервисов, web-серверов
- ПО: Разработка ПО, благодаря своей производительности
