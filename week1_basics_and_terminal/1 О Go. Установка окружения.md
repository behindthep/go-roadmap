### Go
Go - ЯП, разработанный Google в 2009. Серверный ЯП, благодаря **строгой типизации**.
- **Компилируемый**: Код компилируемого языка выполняется намного быстрее, чем интерпритируемого.
- **Многопоточный**: Go умеет тщательно использовать все ресурсы всех ядер процессора (Python, Java рассчитаны на 1 ядро).
С помощью **goroutine** разбивать множество процессов и выполнять их параллельно. Они занимают мало места и требуют мало ресурсов системы.

### SDK
С *https://golang.org/* скачать **Go SDK** (Software Development Kit) - пакет инструментов разработчика. В него входят:
- Компилятор - превращает код на Go в готовый исполняемый файл (.exe для Windows, бинарник для Linux/macOS).
- Стандартная библиотека - набор встроенных функций для работы со строками, сетью, файлами и веб-серверами.
- Утилита go - инструмент в командной строке (CLI) для запуска, тестирования, форматирования и сборки программ.

**Бинарный (двоичный) файл** - содержит данные в виде последовательности байтов для считывания и обработки программами или устройствами, а не для прямого чтения человеком.
- занимают меньше места на диске.
- компьютер считывает и загружает их быстрее, так как не нужно тратить ресурсы на парсинг текста и перекодировку.

```bash
go # Проверка установки

go run main.go # Компиляция во временный исполняемый файл на HDD (в папке временных файлов ОС) и его запуск и удаление после завершения работы программы.
go run -work main.go # Увидеть путь к созданной временной ПАПКЕ

go build main.go # Собирает из файла исполняемый .exe файл (бинарник для Linux/macOS) (2 MB - мало) в текущую папку проекта. 
```

### Расширение Go в VS Code
Расширение Go (от Google) в **VS Code** связывает редактор с инструментами разработки:
- Языковой сервер gopls - «умные» функции: автодополнение кода (IntelliSense), переход к определениям функций, поиск ошибок на лету, автоформатирование при сохранении.
- Отладчик dlv (Delve) - добавляет графический dbug: ставить точки останова (breakpoints) и пошагово проверять значения переменных.
- Набор линтеров и утилит (загружаются по кнопке Install All) - автоматизируют рутину: генерацию тегов для структур (json:""), заготовки для тестов и глубокий анализ кода на скрытые баги (staticcheck).

### Сферы применения языка Go
- Построение web-сервисов, web-серверов.
- Разработка ПО, благодаря производительности.
