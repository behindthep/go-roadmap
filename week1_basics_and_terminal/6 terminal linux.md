Навык работы в терминал - основа backend-разработчика.

username@computrename

`$` в строке приглашения ввода команд - режим обычного пользователя, а не админа.

Отправленную команду в терминале интерпритирует shell и заставляет ОС выполнить то что ожидается от команды.
shell - командная строка (Bash, Zsh (более современная версия), Fish, Ksh, PowerShell, cmd).

Shell (оболочка) — программа-интерпретатор, переводит команды на язык ОС.
Bash (Bourne Again SHell) и Zsh (Z SHell) — реализации оболочки. Командной строкой (или терминалом) называют окно, в котором пишете текст.

Терминал — программа-окно (оболочка-контейнер). телевизор и телеканал:
• Терминал (эмулятор терминала) — экран (окно) с графическим интерфейсом. отображение текста, вкладки и передачу нажатий клавиш.
• Командная строка (интерпретатор / shell) — программа внутри окна, читает то, что написали, переводит на язык ОС и возвращает результат.
В одном окне терминала можно переключаться между разными командными строками.

Представьте цепочку взаимодействия с компьютером:
• Терминал (эмулятор терминала) — графическое окно на экране (приложение Windows Terminal или iTerm2). Принимает нажатия клавиш и выводит текст, но сам не умеет выполнять команды.
• Shell (оболочка) — «мозг», запущен внутри терминала. Программа-переводчик, берет введенную команду, понимает ее и передает ядру ОС на исполнение.
• Bash и Zsh — разные «марки» или версии программы Shell (как Chrome и Firefox — разные браузеры). Оба интерпретатора принадлежат к одному семейству (Unix-оболочки).

```bash
pwd
/home/alex
```

/ - корневой (root) каталог, из которого растёт вся файловая система UNIX.
Диски, флэшки просто монтируются в файловую систему (нет дисков как на Windows).

### Package Manager

Пакетный менеджер, чтобы устанавливать программы через CLI.
Уже есть в системе, умеет скачивать из своего проверенного хранилища пакеты. В хранилище только надёжные программы с открытым исходным кодом.

Пакеты = программа.

Debian, Ubuntu - apt
Fedora - dnf
Mac - brew (отдельная установка)

UNIX — фундаментальная ОС, созданная в 1969 в Bell Labs, заложила стандарты работы современных ОС (многозадачность, файловая система, права доступа).
Linux — Open Source «клон» (Unix-подобная система) Линуса Торвальдса выпущенный 1991 с нуля по образу UNIX, но без использования его исходного кода.
• Классический UNIX — это закрытые коммерческие системы, принадлежащие корпорациям.
• Назначение: Linux работает везде — от смартфонов (Android) и домашних ПК до суперкомпьютеров. UNIX сейчас используется почти исключительно на дорогих корпоративных серверах и мейнфреймах.
• Linux — только ядро ОС (на основе которого делают дистрибутивы вроде Ubuntu). UNIX — это полноценная, цельная ОС.
• К UNIX относятся macOS (сертифицирована как UNIX), Solaris, AIX, FreeBSD (прямой потомок). К Linux — Ubuntu, Debian, Fedora, Astra Linux.

Дистрибутив (distribute — распространять) — готовая к установке и использованию сборка ПО.
• Ядро ОС — это как двигатель автомобиля. Само по себе оно не умеет работать с экраном, мышью или запускать браузер.
• Дистрибутив — это готовый автомобиль: то же ядро (двигатель), но уже с оболочкой (кузовом), настройками, установщиком и набором базовых программ (браузер, плеер, файловый менеджер).
Ubuntu, Mint, Debian, Astra Linux основаны на одном ядре Linux, но выглядят и настраиваются по-разному.

На свеже-установленном дистрибутиве надо написать:

```bash
sudo apt update # Обновить список пакетов и получать актуальные программы через пакетный менеджер.


sudo # Повышает полномочия для 1 команды, как будто она запущена от root (admin).

sudo apt install neofetch # Для установки пакета через пакетный менеджер всегда использовать sudo.
```

После ввода пароля для sudo, повторый ввод не нужен 15 минут.

Способ установки безопаснее, чем привычное ковыряние по сайта и скачивание .exe.

#### Управление потоками

Перенаправить ввод из командной строки в файл

```bash
echo "good night sergnant" # печатает аргументы переданные в кавычках

echo "good night sergnant" > filename # указывает, что и куда записывать. перезаписывает файл
echo "good night sergnant" >> filename # добавляеть в конец сущ. файла
```

Перенаправления возможные за счёт управления потоками:
- stdin  0 - отдавай программе данные, например вводя с клавиатуры. Делаем это через stdin
- stdout 1 - программа возвращяет ответ. Делает это через stdout
- stderr 2 - программа отправляет ошибки в stderr

Чтобы результат одной программы сразу поподал в другую:

| - pipeline (конвеер). прямой слэш

```bash
command1 | command2

ls | grep ".img" # увидеть список всех файлов текущей dir с расширением (extension) .img

grep ".img" # ищет по строке
```

Программы могут свободной общаться между собой.
Можем написать свою прогу и перенаправлять в неё результаты вывода других.
Например прога принимает текст и возвращет его в радужной расцветке.

```bash
./rainbow
asddsa
asddsa # в радужном цвете
```

Ctrl + D - конец файла. Сигнал программе, что я ввёл всё что хотел.

```bash
./rainbow < rainbow.app # подать на вход программе её же исходный текст
```

Номера потоков - обращаться к конкретным потокам.

```bash
cat missing_file 2> /dev/null # перенаправление вывода ошибок программы куда захотим. в терминале вывода не будет

/dev/null # Псевдо устройство. Всё что туда поподает удаляется.
```

Tab - автодопленение команды.

```bash
history # история команд
```

Ctrl + U - очистить всё что ввёл
Ctrl + W - удалить одно слово
Ctrl + C - прервать выполнение программы

#### Удаление файла

```bash
rm filename

rm -r more # удалить dir и все файлы в ней
```

Удаляет с диска. Простой операции восстановления в UNIX нет, в корзину не поподают.


Многие команды принимают флаги - параметры, влияют на работу команды. Начниаются с - или --

```bash
ls -a # flag покажет все скрытые файлы (начинается с . точки. в них системная инф.)
.bashrc # скрытый файл настроек терминала


ls -l # вывод полезной инф. о файлах
dr-xr-xr-x

d # dir
- # файл

rwx # Первая группа прав. действия которые я как владелец файла могу делать с этим файлом
r 4 - read
w 2 - write. модифицировать
x 1 - execute. исполнять файл, заставить процессор исполнять машинный код
```

Прочерк - вместо буквы означает отсутсвие права.

Вторая группа прав - права на файл для группы пользователя, который их создал
Третья - остальные

UNIX разрабатывался как многопользовательская ОС.
С помощью прав запретить другому пользователю чтение или модификацию файла.

```bash
chmod 777 rainbow # поменять права на файл
```

777 - все права для всех
000 - никаких прав для всех

```bash
chown # поменять владельца и группу файлов
```

Возвращяемся к выводу ls -l:

2 столбец (после прав) - количество жёстких ссылок на файл или dir.
3 - владелец
4 - группа владельца
5 - размер файла в байтах
6 - дата и время последнего изменения

```bash
touch rainbow # к уже сущ. файлу обновить время из столбца 6
```

Флаги объеденять:

```bash
# вместо
ls -l -a
ls -la
```

#### Настройка оболочки

```bash
sudo apt install zsh
zsh --version

chsh -s $(which zsh) # заменить оболочку bash на zsh
```

Перезапустить терминал, выбрать 2-ой пункт - как хотим настроить zsh.
Дальше нужен софт для настройки - oh my zsh. Устанавливается командой с сайта.

Команды для работы с сетью (скачать):

```bash
curl
wget
```

Установка темы с иконками:
- скачать шрифт Nerd Fonts, установить его в качестве основного в настройках терминала (там же поставить фон, заблюрить фон)
- в репозитории oh my zsh ищем пункт установки темы. Копируем команду.
- Редактируем конфиг в домашней dir и указываем нашу тему вместо дефолтной.

```bash
nano .zshrc

ZSH_THEME="powerlevel10k/powerlevel10k"
```

Сохранить файл - Ctrl + X, Y, Enter.

После перезапуска в терминале откроются настройки внешнего вида.
Цвета отображения редактируются в настройках самого терминала.

##### Плагины oh my zsh

Список доступных плагинов есть на github.

Некоторые идут из коробки. Чтобы их включить - дописать в строку:

```bash
nano .zshrc

plugins=(git z)
```

z - плагин позволяет быстро попасть в dir в котоой я уже был, написав z и пару букв из названия той dir и не важно насколько далеко по файловой системе находишься.

Сторонние плагины:
```bash
zsh-autosuggestions # автокомплит, подсказывает команды
zsh-syntax-highlighting # подсветка синтаксиса
```

Прнцип установки одинаковый:
- скопировать команду установки
- зайти в конфиг, в строчке plugins добавить его название
