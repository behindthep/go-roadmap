### Go - статически и строго типизированный язык. Это дает максимальную скорость работы и безопасность.
1. Статическая vs Динамическая. Когда проверяются типы
- **Статическая** (Go, Java, C++): Тип переменной известен на этапе компиляции и не может измениться. Ошибки типов видны еще до запуска программы.
Каждый оператор в программе проверяется во время компиляции. Тип данных связывается с переменной при объявлении.
- **Динамическая** (Python, JavaScript, PHP): Тип привязан не к переменной, а к значению в ней. Переменная хранить строку, через строку кода — число. Ошибки типов обнаруживаются уже во время работы.
2. Строгая (Сильная) vs Слабая. Насколько язык строг к смешиванию
- **Строгая** (Go, Python): Переменной закреплён тип данных, и язык запрещает неявные (автоматические) преобразования между ними.
    - Никакого автоматического приведения типов: не можете сложить int и float64 или строку, даже если в них совместимые данные (5 + 2.5 ошибку компиляции). Даже если вы создали свой тип на основе существующего, для Go это разные сущности. Они не приводятся автоматически и их нельзя сравнивать.
    - Явный перевод: Чтобы соединить разные типы, преобразовать тип: float64(myInt) + myFloat.
    - Безопасность при компиляции: Все нестыковки типов компилятор проверяет до запуска программы. Если типы не совпадают, код не скомпилируется. Защищает от случайных багов и опечаток в рантайме.
    Единственное исключение: Бестиповые константы — могут временно подстраиваться под тип переменной при присвоении, но только пока тип не зафиксирован.
- **Слабая** (JavaScript, PHP, C): Язык пытается угадать и автоматически приводит типы за вас. В JS выражение "5" + 2 ="52", а "5" - 2 = 3. Удобно, но порождает скрытые баги.
3. Утиная типизация (Duck Typing)
- Популярна в динамических языках (Python, JS). «Если это выглядит как утка, плавает как утка и крякает как утка, то это утка».
- Программе неважно, какого именно класса объект, главное — чтобы у него был вызванный метод. В Go есть её строгий аналог — интерфейсы, которые проверяются еще при компиляции.

### Разницу между var, := и const:
#### 1. Выделение памяти и адресация (RAM)
- **var** — физически выделяет память в RAM (на стеке или в куче). К ней можно применить оператор взятия адреса &myVar.
- **:=** — работает точно так же, как var: выделяет память в RAM и поддерживает взятие адреса через &.
- **const** — не выделяет память в RAM и не имеет адреса. Существует только на этапе компиляции, компилятор просто подставляет значение в код (inline). Попытка вызвать &myConst вызовет ошибку компиляции.
#### 2. Область видимости (Где можно объявить)
- **var** — универсальна. Объявляется как внутри функций, так и глобально вне их (на уровне пакета). Если имя с заглавной буквы, её можно экспортировать в другие пакеты.
- **:=** — ограничена. Доступна строго внутри функций. Идеальна для локальных счетчиков в циклах for или коротких проверок в if.
- **const** — универсальна. Как и var, объявляется везде (и внутри, и вне функций). Поддерживает экспорт в другие пакеты при написании с заглавной буквы.
#### 3. Обязательность инициализации (Когда задавать значение)
- **var** — необязательна. Если значение не указано, нужно обязательно написать тип (var x int). Переменная автоматически получит дефолтное нулевое значение типа (zero-value: 0, "", false или nil).
- **:=** — строго обязательна. Нельзя опустить значение или явно указать тип данных (a := int или a := ошибочны).
- **const** — строго обязательна. Значение должно быть четко определено и известно еще на этапе компиляции.
#### 4. Допустимые типы данных
- **var** — поддерживает любые типы данных (базовые, слайсы, массивы, структуры, интерфейсы, функции и т.д.).
- **:=** — поддерживает любые типы данных, так как это просто сокращение для var.
- **const** — поддерживает только базовые типы: числа (целые, с плавающей точкой, комплексные), строки и булевы значения. Создать константный слайс, массив или структуру в Go нельзя.
#### 5. Множественное объявление (В несколько переменных)
- **var** — поддерживает группировку в блоки var (...) на несколько строк. В одну строку можно объявить несколько переменных (например, var a, b = 1, "ok"), но указывать разные типы в одной строке явно нельзя — их нужно опустить для автоматического вывода.
- **:=** — не поддерживает группировку в круглые скобки. Позволяет объявлять разные типы в одну строку (например: name, age := "Alice", 30).
- **const** — поддерживает блоки const (...). Если внутри блока пропустить значение для следующей строки, Go автоматически скопирует выражение из предыдущей. Также внутри таких блоков доступен автоинкремент iota.
#### 6. Специфика типизации (Вывод типов)
- **var** и **:=** — если тип не указан явно, он жестко фиксируется при первом присвоении, выбираясь из списка дефолтных типов (5 станет int).
- **const** — могут быть «бестиповыми» (untyped). Это уникальная фича констант: они остаются «чистым значением» и автоматически подстраиваются под тип выражения, в котором используются, без ручного приведения (например, const Pi = 3.14 сработает и с float32, и с float64).

### byte
byte: в 1 байте 8 бит. 1024b = 1kb...
byte, если нужно очень много записать, вместо string, string занимает больше места на 1 символ.

В Go много работы с byte:
- Чтение файла происходит в byte
- Ответ на запрос к сайту приходит в byte. По сети передаются byte

Получаем в byte, затем преобразуем в необходимый тип, человекопонятный вид.

### Типы данных
Данные в памяти - набор битов.
Типы данных определяют, какие значения храниться в переменных (как данные интерпретируются) и какие операции можно выполнять с этими значениями.

Go имеет встроенные типы и позволяет определять свои. Встроенные типы данных:

#### Целочисленные типы:
Два типа числовых данных, которые отличаются характером их размеров (статическим или динамическим).
Большинство системных архитектур сегодня 32 / 64 -битные.
- независимые от архитектуры типы (int32), размер данных в битах постоянный, независимо от того, на какой машине выполняется код / для какой архитектуры компилируете код.
- зависимым от архитектуры. int при компиляции для 32-битной архитектуры, размер 32 бита. Если программа скомпилирована для 64-битной архитектуры, переменная размер 64 бита.

Диапазоны основаны на размере бита. Для двоичных данных 8 битов могут представлять 256 уникальных возможных значений.
**Архитектурно-независимые** целочисленные типы:
- int8:         от -128                       до 127                        занимает 1 байт (8 бит).
- int16:        от -32768                     до 32767                      занимает 2 байта (16 бит)
- int32 / rune: от -2147483648                до 2147483647                 занимает 4 байта (32 бита)
Если byte и uint8 – это одни и те же данные, rune может быть одним байтом или четырьмя байтами (диапазоном, определяемым int32). rune для представления символа Unicode, а символы ASCII могут быть представлены только int32.
- int64:        от –9 223 372 036 854 775 808 до 9 223 372 036 854 775 807  занимает 8 байт (64 бита)
- uint8 / byte: от 0                          до 255                        занимает 1 байт
Прояснить, когда в элементах символьных строк программа использует байты в качестве общего вычислительного измерения (в отличие от маленьких целых чисел, не связанных с таким измерением данных). byte и uint8 после компиляции программы идентичны, byte чаще используется для представления символьных данных в числовой форме, uint8 в программе представлен числом.
- uint16:       от 0                          до 65535                      занимает 2 байта
- uint32:       от 0                          до 4294967295                 занимает 4 байта
- uint64:       от 0                          до 18 446 744 073 709 551 615 занимает 8 байт

**Зависимые от архитектуры** типы:
- **int**:      целое число со знаком. В зависимости о платформы занимает в памяти 4 байта (int32) / 8 байт (int64).     either 32 or 64 bits
- **uint**:     целое число беззнаковое. В зависимости о платформы занимает в памяти 4 байта (uint32) / 8 байт (uint64). either 32 or 64 bits

*uintptr* — беззнаковый целочисленный тип данных, размер в байтах всегда = размеру указателя на конкретной архитектуре процессора (32 бита / 4 байта на 32-разрядных системах и 64 бита / 8 байт на 64-разрядных системах). не является ссылкой на объект в памяти. число (адрес), которое может хранить битовое представление указателя.

int и uint имеют наиболее эффективный размер для определенной платформы (32 или 64 бита). Это наиболее используемый тип для представления целых чисел в программе.
Различные компиляторы могут предоставлять различный размер для этих типов даже для одной и той же платформы.

Если для переменной явно не указан тип, но ей присвоено целочисленное значение, ее тип будет int.

#### Числа с плавающей точкой:
- float32: от 1.4*10-45  до 3.4*1038  (для положительных). в памяти 4 байта IEEE-754 32-bit floating-point numbers. Обеспечивает 6  десятичных цифр точности.
- float64: от 4.9*10-324 до 1.8*10308 (для положительных). в памяти 8 байт  IEEE-754 64-bit floating-point numbers. Обеспечивает 15 десятичных цифр точности.

**Действительные** числа (вещественные числа (R) — все числа, которые можно разместить на числовой прямой).
Числа с плавающей точкой (float) используются для представления действительных чисел, которые не могут быть выражены как целые числа.
Множество действительных чисел состоит из объединения двух непересекающихся множеств:
**рациональные** (можно представить в виде обычной дроби) и **иррациональные** (pi или sqrt(2) имеют бесконечную и непериодическую последовательность цифр после запятой) числа. Компьютерная память конечна, записать или сохранить иррациональное число в точности внутри типа float невозможно.

#### Комплексные числа:
- complex64:  вещественная и мнимая части представляют числа float32. var f complex64  = 1+2i
- complex128: вещественная и мнимая части представляют числа float64. var g complex128 = 4+3i

complex64   complex numbers with float32 real and imaginary parts
complex128  complex numbers with float64 real and imaginary parts

#### Логический тип bool. Одно из двух значений: true  или false.
Значения true и false всегда будут объявляться строчными буквами t и f, это их предварительно объявленные идентификаторы в Go.

#### Строки. string:
В Go строке соответствует строковый литерал - последовательность символов.
Структура данных байтовый срез, доступный только для чтения. Байт в строке представляет часть символа в кодировке UTF-8, является кодировкой переменной длины и может представлять любой символ Unicode.

Строки в Go неизменяемы, после создания строки ее содержимое нельзя изменить напрямую.

Строка может содержать управляющие последовательности, начинаются с обратного слеша \:
- \n: переход на новую строку
- \r: возврат каретки
- \t: табуляция
- \": двойная кавычка внутри строк
- \\: обратный слеш

- `` - **необработанный строковый литерал**. символы внутри обратных кавычек отображаться как записаны, за исключением символа обратной кавычки.
a := `Say "hello"
to Go!\n`
Say "hello"
to Go!\n
- "" - **интерпретируемый строковый литерал**. Внутри кавычек любой символ, кроме новой строки и незакрытых двойных кавычек. двойные кавычки внутри - обратный слэш в качестве escape-символа.
a := "Say \"hello\" to Go!"

##### Строки с символами UTF-8
UTF-8 – схема для кодирования символов переменной длины 1-4 байта. Для данных UTF-8 (специальных символов 世) тип-псевдоним rune (int32), может состоять из 1-4 байтов.
Римские символы (A), могут быть представлены значением ASCII (65).

for и range для индексации любых строк Go, подсчета байтов в строке. range индексирует символы в строке, возвращая за раз один символ и индекс байта, в котором находится символ в строке.

```go
a := "Hello, 世界"
for i, c := range a {
    fmt.Printf("%d: %s\n", i, string(c))
}
fmt.Println("length of 'Hello, 世界': ", len(a))

// 0: H
// 1: e
// 2: l
// 3: l
// 4: o
// 5: ,
// 6:
// 7: 世  символу требуется 3 байта
// 10: 界
// length of 'Hello, 世界': 13  строка длиннее, чем количество символов
```

#### Значение по умолчанию
Если переменной не присвоено значение, она получает значение по умолчанию для ее типа:
- Для числовых типов:   число 0
- Для логического типа: false
- Для строк:            "" (пустая строка)

#### Неявная типизация
При определении переменной можем опускать тип, если явно инициализируем переменную значением. Компилятор на основе значения неявно выводит тип переменной:
- Если присваивается целое число,  переменная представляет int
- Если присваивается число с плавающей точкой,  переменная float64

Если не указываем у переменной тип, ей нужно присвоить начальное значение. Объявление без типа и начального значения ошибкой.

**Узнать тип переменной** - спецификатор "%T" при выводе с помощью функции: fmt.Printf("age type: %T\n", age) // age type: int

#### Выбор размера
Выбор правильного размера больше зависит от производительности целевой архитектуры, чем от самих данных.
Если не знаешь последствия для производительности программы:
Для целочисленных данных используются зависимые типы, int или uint, вместо int64 или uint64. увеличивает скорость обработки для целевой архитектуры.
- int64 и компилируете код в 32-битной архитектуре, для обработки значений минимум вдвое больше времени, для перемещения данных по архитектуре доп циклы ЦП.
- int, программа подстроится под архитектуру и быстрее обрабатываться.

заранее знаете, не будете превышать определенный диапазон размеров, архитектурно-независимые типы – увеличить скорость и уменьшить использование памяти.
знаете, данные не превысят значение 100 и только положительны, uint8 программу более эффективной, потребует меньше памяти.

#### Переполнение и сворачивание данных
Превысим диапазоны в программе. сохранить значение, превышает размер типа, Go переполнить и свернуть число. зависит, когда вычислено значение – во время компиляции или выполнения.
Ошибка компиляции, когда программа находит ошибку при сборке программы.
Ошибка выполнения после компилиляции в момент ее фактического запуска.

```go
var maxUint32 uint32 = 4294967295 // Max uint32 size
```
Если во время выполнения прибавить 1 - свернется до 0.

Добавив 1 к переменной при ее назначении, до компиляции:
```go
var maxUint32 uint32 = 4294967295 + 1
```
Если время компиляции компилятор определить, что значение велико для хранения в указанном типе, ошибку constant 4294967296 overflows uint32.
